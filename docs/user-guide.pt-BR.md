# Guia de Uso

## Fluxo recomendado

1. Abra o Outlook Clássico.
2. Abra o Outlook Part Sender.
3. Selecione a conta de envio.
4. Preencha Para / CC / BCC.
5. Escreva o assunto base e a mensagem.
6. Monte as Partes.
7. Revise Parte → Anexos.
8. Mantenha **Rascunhos**.
9. Valide e gere.
10. Confira os rascunhos no Outlook e envie.

## Como montar as Partes

### Modo rápido — Arquivos → Partes

Selecione vários arquivos. Cada arquivo vira uma Parte separada.

### Modo personalizado — Nova Parte

Crie uma Parte, selecione-a e anexe um ou vários arquivos nela.

Use Subir/Descer para alterar a ordem. A numeração final segue a ordem exibida.

## Alerta de tamanho

O padrão é 20 MB estimados por e-mail. O valor é apenas informativo; o limite real depende dos servidores.

## Salvar montagem

Use Salvar montagem quando um lote grande demora para ser preparado. Carregar montagem restaura a estrutura e volta o modo para Rascunhos.

## Primeiro teste seguro

Use seu próprio e-mail e confirme todos os rascunhos antes do primeiro envio real.
