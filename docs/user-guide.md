# User Guide

## Recommended workflow

1. Open Classic Outlook.
2. Launch Outlook Part Sender.
3. Select the sending account.
4. Fill To / CC / BCC.
5. Enter the base subject and common message.
6. Build the Parts.
7. Review Part → Attachments.
8. Keep **Drafts** selected.
9. Validate and generate.
10. Review the Outlook drafts and send them.

## Building Parts

### Quick mode — Files → Parts

Select multiple files. Each file becomes a separate Part.

### Custom mode — New Part

Create a Part, select it and attach one or more files to that Part.

Use Up/Down to reorder Parts. Final numbering follows the displayed order.

## Size warning

The default warning threshold is 20 MB per estimated email. This is informational; actual limits vary by sender and recipient systems.

## Saved layouts

Use Save layout when a large multi-part package takes time to prepare. Load layout restores the mapping and returns the send mode to Drafts.

## Safe first test

Always make the first test against your own mailbox and confirm the generated drafts.
