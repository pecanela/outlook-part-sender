# Outlook Part Sender v2.0.0 — First VSTO Migration

**Status:** Superseded / Pre-release

First attempt to move the tool inside Classic Outlook as an application-level VSTO add-in.

## Highlights

- Outlook Ribbon button.
- `ThisAddIn.Application`.
- Dynamic Parts and multiple attachments.
- Save/load layouts.
- Draft/Send protection.
- VSTO ClickOnce build/publish scripts.
