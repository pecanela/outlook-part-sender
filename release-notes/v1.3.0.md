# Outlook Part Sender v1.3.0 — Dynamic Parts

**Status:** Legacy

Major data-model change: one **Part** became one email, and each Part could contain multiple attachments.

## Highlights

- No fixed number of parts.
- Multiple attachments per Part.
- `Arquivos -> partes`.
- `+ Nova parte`.
- Attachment panel per Part.
- Part reordering and automatic renumbering.
- `.opsparts.json` save/load.
- Part-level size estimation.
