# Outlook Part Sender v3.0.0 — One Click COM Add-in

**Status:** Legacy experiment

Introduced a per-user COM Add-in with a `Part Sender` Ribbon tab.

## Highlights

- Outlook Ribbon integration.
- Local .NET Framework compilation.
- Per-user HKCU registration.
- No Visual Studio/VSTO/admin required.
- Diagnostics and uninstaller.
- Preserved all multi-part mail features.

## Why it was replaced

Although technically convenient, registering an Outlook add-in is more likely to conflict with restrictive corporate endpoint policies. v3.1.0 moved to a portable external utility.
