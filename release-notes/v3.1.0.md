# Outlook Part Sender v3.1.0 — Portable Corporate

**Status:** Latest / Recommended

## What problem does this release solve?

Outlook Part Sender is useful when a document package is too large to send as one email.

Instead of manually creating a sequence like:

```text
Project Documentation - Part 01/07
Project Documentation - Part 02/07
...
Project Documentation - Part 07/07
```

and repeatedly copying recipients, message text and attachments, you prepare the delivery once and let the program create the numbered Outlook messages.

Each Part can contain one or several specific attachments.

The default mode creates **Drafts**, giving you a final review before sending.

## Why v3.1.0?

This release adopts the architecture that worked best on a managed corporate Windows PC:

- portable;
- no installer;
- no Outlook add-in;
- no Outlook registry modification;
- no VBA/VSTO;
- no administrator privileges;
- no PowerShell dependency in the launcher;
- source code included.

## Main features

- Dynamic number of Parts.
- Multiple attachments per Part.
- Files → Parts quick mode.
- Custom attachment grouping.
- To / CC / BCC.
- Sending-account selection.
- Automatic `Part NN/NN` numbering.
- Outlook default signature through WordEditor.
- Part → Attachment review.
- Reordering before generation.
- Saved layouts.
- Per-Part size estimates.
- Recipient validation through Outlook.
- Drafts by default.
- Automatic Send requires a second confirmation.
- Immutable batch snapshot during processing.
- Partial-failure diagnostics with batch ID.

## Typical workflow

```text
Open Classic Outlook
        ↓
Run Outlook Part Sender
        ↓
Enter To / CC / subject / message
        ↓
Create Parts
        ↓
Assign attachments
        ↓
Review Part → Attachments
        ↓
Create Drafts
        ↓
Review in Outlook
        ↓
Send
```

## Requirements

- Windows 10/11.
- Classic Outlook for Windows.
- .NET Framework 4.x.
- Endpoint policy allowing local execution and Outlook COM automation.

**New Outlook is not supported.**

## Upgrade

Recommended for all users of older versions.

## Corporate environments

The portable design minimizes changes to the computer, but company endpoint policies can still block `.cmd`, `csc.exe`, `%LOCALAPPDATA%` executables or Outlook COM automation.

The project does not attempt to bypass those controls.
