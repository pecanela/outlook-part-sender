# Outlook Part Sender v1.0.0 — Initial Prototype

**Status:** Prototype

First functional release.

## Highlights

- Same recipients/message across multiple emails.
- Automatic `Parte 01/NN` subject numbering.
- One attachment per email.
- Outlook account selection.
- Drafts as default.
- Optional automatic sending.
- PowerShell + Outlook COM launcher/installer concept.
